# Practice 5: Regular Expressions in Python

## Overview
This practice focuses on mastering regular expressions in Python using the `re` module. The main task involves parsing receipt data from a `raw.txt` file to extract meaningful information.

## Learning Objectives
- Understand RegEx syntax, metacharacters, and special sequences
- Use `re.search()`, `re.findall()`, `re.split()`, and `re.sub()` functions
- Extract structured data from unstructured text
- Parse real-world receipt data
